# rift.movement.pathfinding.bfs

Smart pathfinding using a Breadth-First Search (BFS) algorithm. Based on the rsmod pathfinding library.

## Usage

Installing the plugin gives no one BFS pathfinding. Give it out one of two ways:

- **On a node**: in Forge, select the **Player** node (or an NPC), then **Add Component → BfsPathfinding**.
- **As a script**: in **Project › Project Settings… › Plugins › Installed**, select **BFS pathfinding**, click **Use template…** and pick **players-pathfind**, then **Build**. Every player gets it as they log in.
